# Ramrup Satpati | Systems & AI Software Engineer Portfolio

Cinematic, maximalist, animation-heavy portfolio featuring the **SpaceEdu** planetary video hero and Ramrup Satpati's core engineering domains: **Python & AI/ML**, **Rust Systems**, and **Vue.js Frontend**.

## 🚀 Features

- **Cinematic Planetary Hero (SpaceEdu)**
  - Full-viewport looping 4K background video streams for Earth, Venus, and Mars with fallback posters.
  - Interactive flanking side-slots with transparent 2048px planet cutouts and responsive serif labels.
  - Custom `--u` mathematical scaling coordinate engine across 6 responsive tiers.
  - Reversible zero-latency (<2ms) planet switching with video pre-warming.
  - Choreographed entrance animation sequence with masked text reveals and settled pills.
  - Cosmic Astronomy vs. Engineering Ecosystem domain mode toggle.

- **What I Bring to the Table**
  - Python & AI/ML (PyTorch Deep Learning MCQ Solver, Gradient Boosting ML price prediction, Healthcare HMS, Open Source Monorepo).
  - Rust Systems (Low-level systems programming, memory safety without GC, high-concurrency CLI tools, zero-cost abstractions).
  - Vue.js Frontend (Reactive web interfaces, SPA architectures, custom component libraries).
  - Interactive animated physics-based Neural Constellation Canvas connecting the stack.

- **Interactive In-Card Demos**
  - PyTorch MCQ Solver Transformer inference simulator with candidate token attention probabilities.
  - Gradient Boosting regression calculator with dynamic sliders and SHAP marginal gains.
  - Tokio & Rayon multi-threaded CLI benchmark runner (14.2M lines/sec).

- **Interactive Architecture REPL & CLI Sandbox**
  - Run real Python, Rust, and Vue snippets with simulated compiler execution and latency logs.
  - Interactive terminal command line interpreter (`help`, `skills`, `projects`, `whoami`, `contact`, `clear`).

- **Architecture Modal & Direct Contact**
  - Deep-dive into project pipelines, architecture diagrams, and copyable implementation sources.
  - Direct transmission form and direct channel to `ramrupsatpati@gmail.com`.

- **Bonus Self-Contained Standalone HTML**
  - `public/spaceedu-standalone.html`: Single self-contained HTML file with zero build step, no frameworks, and all CSS/JS inline.

## 🛠️ Quickstart

### Prerequisites
- Node.js 18+ (or Bun / pnpm / yarn)

### Installation
```bash
# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit `http://localhost:3000` in your browser.

### Production Build
```bash
# Build production bundle
npm run build

# Preview production build
npm run preview
```
